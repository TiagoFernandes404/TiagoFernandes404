## 👨‍💻 About Me
I'm a Computer Science graduate from the **University of Minho**, passionate about understanding how systems work beneath the surface — from compilers and concurrent architectures to graphics engines and databases.
I enjoy tackling projects that push me to go deeper, whether that means building a real-time multiplayer game in Erlang, writing a compiler from scratch, or designing a 3D solar system in OpenGL. For me, programming isn't just about writing code — it's about solving interesting problems in elegant ways.
- 🎓 BSc in Computer Science @ University of Minho
- 🔍 Interests: Concurrent Systems · Compilers · Computer Graphics · Databases · Data Engineering
- 🌍 Based in Portugal
- 🚀 Always looking for the next challenge
